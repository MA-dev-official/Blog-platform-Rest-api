# Node.js Express Application

## Overview
A simple Node.js Express server application running on Replit.

## Project Structure
- `index.js` - Main Express server entry point
- `package.json` - Node.js dependencies and scripts

## Running the Application
The application runs on port 5000 and is started with:
```
node index.js
```

## API Endpoints
- `GET /` - Returns the main welcome page
- `GET /api/health` - Returns health check JSON

## Dependencies
- Express.js for the web server
